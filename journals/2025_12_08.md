O CreateOrUpdateInstrumentMarketRequest é um DTO interno para alimentar CreateOrUpdateInstrumentAsync (fonteCMD = false). Ele preenche campos de ativo de mercado: código/nome, mercados, datas de início/fim, TpOpcao, TpExercicio, TpBarreira, VlrBarreira, NumContrato, NumDiasLiq, Taxa (strike), emissor, flags, etc. Com fonteCMD=false, o bloco de dados CMD (TbAtivoComDinheiro, CodMarcacaoAtivo, etc.) não é executado; só persistem TbAtivo, TbAtivoFonte (ALPHATOOLS, XP, etc., se informados), TbAtivoMercado e TbAtivoOpcao.
- Portanto, nenhum campo específico da CMD é gravado nesse fluxo; o DTO de “Market” é usado apenas para normalizar os dados do ativo antes de salvar nas tabelas Prisma.
