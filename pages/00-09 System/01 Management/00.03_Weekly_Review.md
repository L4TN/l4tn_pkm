# Weekly Review Protocol

## Process (Every Friday 17h-17h30)

### 1. Journal Processing (10min)
- [ ] Open all journals from this week
- [ ] Extract important insights to permanent notes
- [ ] Tag unprocessed TODOs with `#review`
- [ ] Link related journal entries

### 2. Cleanup (10min)  
- [ ] Review pages with "novo", "temp", "untitled" in name
- [ ] Consolidate duplicate notes (nat.md, nat2.md, nat3.md)
- [ ] Archive completed sprints to `14_Work_Sprints/Archive/`
- [ ] Delete orphan pages with zero backlinks

### 3. Project Status (10min)
- [ ] Update [[13_Work_Projects_Index]] with sprint progress
- [ ] Move completed tasks to DONE
- [ ] Plan next week's priorities
