# Naming Conventions

## Journal Entries
- Format: `YYYY_MM_DD.md` (automatic Logseq)
- Location: `/journals/`

## Project Documentation
- Format: `ProjectName_Topic_YYYY-MM-DD.md`
- Example: `Impulso_Auth_2025-12-24.md`

## Sprint Files
- Format: `SprintID_Description.md`
- Example: `14.01_Sprint_Overview.md`

## Task Files  
- Format: `TaskID_ShortDescription.md`
- Example: `14.01_Task_01_Mapeamento.md`

## Temporary Notes
**NEVER use "novo", "temp", "untitled"**
- Use: `_DRAFT_ProjectName_Topic.md`
- Process within 48h or delete

## Indexes
- Format: `CategoryNumber_Category_Index.md`
- Example: `10_Work_Index.md`
