# Guia Completo – Neovim Básico + Split + Terminal (Padrão)

Sem plugins  
Sem customização  
Apenas Neovim puro  

---

# PARTE 1 — NEOVIM BÁSICO

## 1. Abrir o Neovim

Abrir um arquivo:

```
nvim arquivo.txt
```

Abrir vazio:

```
nvim
```

---

## 2. Modos do Neovim

O Neovim funciona por modos.

### Normal Mode
Modo padrão ao abrir.
Usado para navegação e comandos.

Voltar para Normal:
```
Esc
```

---

### Insert Mode
Modo para escrever texto.

Entrar:
```
i  → inserir antes do cursor
a  → inserir depois do cursor
o  → nova linha abaixo
O  → nova linha acima
```

Sair:
```
Esc
```

---

### Visual Mode
Modo para selecionar texto.

Entrar:
```
v  → seleção normal
V  → seleção por linha
```

---

## 3. Navegação (Modo Normal)

Mover cursor:
```
h → esquerda
j → baixo
k → cima
l → direita
```

Mover por palavras:
```
w → próxima palavra
b → palavra anterior
```

Ir para:
```
0  → início da linha
$  → fim da linha
gg → início do arquivo
G  → fim do arquivo
```

---

## 4. Editar Texto

Apagar:
```
x   → apagar caractere
dd  → apagar linha
```

Copiar:
```
yy  → copiar linha
```

Colar:
```
p
```

Desfazer:
```
u
```

Refazer:
```
Ctrl + r
```

---

## 5. Salvar e Sair

Salvar:
```
:w
```

Sair:
```
:q
```

Salvar e sair:
```
:wq
```

Sair sem salvar:
```
:q!
```

---

# PARTE 2 — SPLITS (DIVISÕES)

## 1. Criar Splits

Horizontal:
```
:split
```
ou
```
Ctrl + w + s
```

Vertical:
```
:vsplit
```
ou
```
Ctrl + w + v
```

---

## 2. Navegar Entre Splits

Mover foco:
```
Ctrl + w + h
Ctrl + w + j
Ctrl + w + k
Ctrl + w + l
```

Alternar próxima janela:
```
Ctrl + w + w
```

---

## 3. Redimensionar Splits

Aumentar altura:
```
Ctrl + w + +
```

Diminuir altura:
```
Ctrl + w + -
```

Aumentar largura:
```
Ctrl + w + >
```

Diminuir largura:
```
Ctrl + w + <
```

---

## 4. Fechar Split Atual

```
:close
```

Ou:
```
Ctrl + w + c
```

---

# PARTE 3 — TERMINAL DENTRO DO NEOVIM

## 1. Abrir Terminal

Abrir terminal:
```
:terminal
```

Abrir já dividindo:

```
:split | terminal
```

ou

```
:vsplit | terminal
```

---

## 2. Terminal-Job Mode

Quando você abre `:terminal`, o Neovim entra em:

Terminal-Job mode

Nesse modo:
- Esc NÃO sai
- Ctrl + w NÃO funciona
- As teclas vão direto para o shell (cmd, PowerShell, bash, etc)

---

## 3. Sair do Terminal Mode

Para voltar ao modo Normal:

```
Ctrl + \   depois   Ctrl + n
```

Passos:
1. Ctrl + \
2. Ctrl + n

Agora você voltou ao modo Normal.

---

## 4. Alternar Entre Editor e Terminal

Depois de sair do Terminal-Job mode:

```
Ctrl + w + h/j/k/l
```

ou

```
Ctrl + w + w
```

---

# Fluxo Prático Completo

1. Abrir arquivo:
   nvim arquivo.md

2. Criar split vertical:
   :vsplit

3. Abrir terminal:
   :terminal

4. Sair do terminal mode:
   Ctrl + \  Ctrl + n

5. Alternar entre editor e terminal:
   Ctrl + w + direção

---

# Conceitos Importantes

Windows Terminal:
- Divide janelas da aplicação

Neovim:
- Divide buffers/arquivos
- Pode embutir terminal
- Possui modos diferentes

Terminal dentro do Neovim:
- Não é o mesmo que modo Normal
- Precisa sair com Ctrl + \  Ctrl + n

---

Com isso você cobre:

- Uso básico do editor
- Navegação eficiente
- Edição essencial
- Split de janelas
- Terminal embutido
- Alternância correta entre modos

Tudo apenas com Neovim padrão.
