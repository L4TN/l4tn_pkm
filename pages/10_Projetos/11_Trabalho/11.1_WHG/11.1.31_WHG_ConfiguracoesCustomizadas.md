# Sistema de Configurações Customizadas

## Visão Geral

O sistema de configurações customizadas do Prisma permite carregar e mesclar configurações de múltiplas fontes com ordem de prioridade definida. As configurações podem vir do `appsettings.json`, banco de dados (`TbConfiguracao`), e arquivos específicos de ambiente.

## Arquitetura

### Estrutura de Classes

```
BaseCustomOptionsConfig<T>
    ↓ (herda)
MigracaoRequestCapturaOptionsConfig
    ↓ (usa)
MigracaoRequestCapturaCustomOptions (POCO)
```

- **BaseCustomOptionsConfig<T>**: Classe abstrata base que implementa a lógica de carregamento
- **[Nome]OptionsConfig**: Classes concretas que definem qual enum de configuração (`EConfiguracao`) usar
- **[Nome]CustomOptions**: POCOs (Plain Old CLR Objects) que definem a estrutura dos dados

### Componentes Principais

| Componente | Localização | Responsabilidade |
|------------|-------------|------------------|
| `BaseCustomOptionsConfig<T>` | `Core/IoC/CustomOptions/Base/` | Lógica de carregamento e mesclagem |
| `MigracaoRequestCapturaOptionsConfig` | `Core/IoC/CustomOptions/` | Configuração específica para captura de requests |
| `MigracaoRequestCapturaCustomOptions` | `Core/Domain/Options/` | Modelo de dados (POCO) |
| `IConfiguracaoRepository` | `Core/Domain/Interfaces/Repositories/Whg/` | Acesso ao banco de dados |
| `CustomOptionsDomainService` | `Core/Domain/Services/` | Serialização/deserialização com criptografia |

## Fluxo de Carregamento

### Método Principal: `LoadOptionsFromAppsettingsAndDatabaseAsync`

Localização: `BaseCustomOptionsConfig.cs:114-144`

```csharp
protected async Task LoadOptionsFromAppsettingsAndDatabaseAsync(bool loadDatabase, CancellationToken cancellationToken = default)
{
    // 1. Cria instância vazia
    _current = new();

    // 2. Carrega configurações do appsettings.json base
    Configuration.GetSection(ChaveOptions.ToString()).Bind(_current);

    // 3. Se habilitado, carrega e mescla do banco de dados
    if (loadDatabase)
    {
        await LoadOptionsFromOnlyDatabaseAsync(false, cancellationToken);
    }

    // 4. Em Development/Staging: sobrescreve com arquivo de ambiente
    if (_hostEnvironment.IsDevelopment() || _hostEnvironment.IsStaging())
    {
        // Carrega appsettings.{Environment}.json
        configFile.GetSection(ChaveOptions.ToString()).Bind(_current);
    }
}
```

### Carregamento do Banco de Dados

Localização: `BaseCustomOptionsConfig.cs:85-112`

1. Busca registros na `TbConfiguracao` usando a chave do enum (`EConfiguracao`)
2. Filtra registros com `JsOpcoes` não vazio
3. Ordena por aplicação (genéricos primeiro, específicos depois)
4. Usa `JsonConvert.PopulateObject` para **mesclar** (não substituir) propriedades

```csharp
// O PopulateObject MESCLA as propriedades, mantendo valores não especificados
JsonConvert.PopulateObject(config.JsOpcoes, _current, settings);
```

## Ordem de Prioridade

### Production

```
appsettings.json (base)
    ↓ (sobrescreve)
Banco de Dados (TbConfiguracao)
    ↓ (valor final)
🏆 CONFIGURAÇÃO FINAL
```

### Staging / Development

```
appsettings.json (base)
    ↓ (sobrescreve)
Banco de Dados (TbConfiguracao)
    ↓ (sobrescreve)
appsettings.{Environment}.json
    ↓ (valor final)
🏆 CONFIGURAÇÃO FINAL
```

### Resumo por Ambiente

| Ambiente | Prioridade (menor → maior) | Arquivo de Ambiente Sobrescreve Banco? |
|----------|---------------------------|----------------------------------------|
| **Production** | appsettings.json → **Banco** | ❌ Não (não carrega arquivo de ambiente) |
| **Staging** | appsettings.json → Banco → **appsettings.Staging.json** | ✅ Sim |
| **Development** | appsettings.json → Banco → **appsettings.Development.json** | ✅ Sim |

## Exemplo Prático: MigracaoRequestCaptura

### Estrutura da Configuração

```csharp
public class MigracaoRequestCapturaCustomOptions : ICloneable
{
    public bool Enabled { get; set; } = true;
    public List<string> Routes { get; set; } = new();
    public List<string> SkipRoutes { get; set; } = new();
}
```

### Cenário de Mesclagem

**1. appsettings.json**
```json
{
  "MigracaoRequestCaptura": {
    "Enabled": true,
    "Routes": ["/api/movimentacaoconta/get"]
  }
}
```

**2. Banco de Dados (TbConfiguracao)**
```json
{
  "Enabled": false,
  "SkipRoutes": ["/api/health"]
}
```

**3. appsettings.Staging.json**
```json
{
  "MigracaoRequestCaptura": {
    "Enabled": true
  }
}
```

**Resultado Final em Staging:**
```json
{
  "Enabled": true,           // ← appsettings.Staging.json
  "Routes": ["/api/movimentacaoconta/get"],  // ← appsettings.json
  "SkipRoutes": ["/api/health"]              // ← Banco de Dados
}
```

**Resultado Final em Production:**
```json
{
  "Enabled": false,          // ← Banco de Dados
  "Routes": ["/api/movimentacaoconta/get"],  // ← appsettings.json
  "SkipRoutes": ["/api/health"]              // ← Banco de Dados
}
```

## Configuração no Banco de Dados

### Tabela: TbConfiguracao

| Campo | Descrição |
|-------|-----------|
| `CdConfiguracao` | Valor do enum `EConfiguracao` (ex: `EConfiguracao.MigracaoRequestCaptura`) |
| `JsOpcoes` | JSON com as propriedades a serem mescladas |
| `NmAplicacao` | Nome da aplicação (vazio = genérico, preenchido = específico) |

### Exemplo de Registro

```sql
INSERT INTO TbConfiguracao (CdConfiguracao, JsOpcoes, NmAplicacao)
VALUES (
    50, -- EConfiguracao.MigracaoRequestCaptura
    '{"Enabled": false, "SkipRoutes": ["/api/health", "/api/ping"]}',
    NULL -- Configuração genérica
);
```

## Segurança e Criptografia

### Propriedades Sensíveis

Propriedades do tipo `PasswordVO` são automaticamente criptografadas/descriptografadas usando:

- **Conversor**: `PasswordVOConverter`
- **Chave**: `EncryptionKeysOptions.GenericEncryptKey`
- **Serviço**: `CustomOptionsDomainService`

```csharp
// Ao carregar do banco
new PasswordVOConverter(_encryptionKeysOptions.Value.GenericEncryptKey, encrypt: true)

// Ao salvar no banco
SerializeOptions(objOptions) // Criptografa automaticamente
```

## Boas Práticas

### 1. Configurações por Ambiente

- **Production**: Use o banco de dados para configurações dinâmicas
- **Staging/Development**: Use arquivos de ambiente para sobrescrever e testar sem afetar o banco

### 2. Hierarquia de Configurações

- **appsettings.json**: Valores padrão e seguros
- **Banco de Dados**: Configurações de produção e ajustes dinâmicos
- **appsettings.{Environment}.json**: Sobrescrita local para testes

### 3. Propriedades Sensíveis

- Sempre use `PasswordVO` para senhas e chaves
- Nunca commite arquivos de ambiente com credenciais reais

### 4. Atualização Dinâmica

```csharp
// Para recarregar configurações em runtime
await customOptions.UpdateOptionsAsync(cancellationToken);
```

## Troubleshooting

### Configuração não está sendo aplicada

1. Verifique a ordem de prioridade (arquivo de ambiente pode estar sobrescrevendo)
2. Confirme que o nome da seção no JSON corresponde ao enum `EConfiguracao`
3. Em Staging/Dev, verifique se `appsettings.{Environment}.json` existe e tem prioridade

### Banco de dados não está sendo lido

1. Verifique se `loadDatabase` está `true` em `LoadOptionsAsync`
2. Confirme que existem registros em `TbConfiguracao` com o `CdConfiguracao` correto
3. Verifique logs de erro no carregamento

### Valores inesperados após mesclagem

Lembre-se: `JsonConvert.PopulateObject` **mescla** propriedades, não substitui o objeto inteiro. Propriedades não especificadas mantêm seus valores anteriores.
