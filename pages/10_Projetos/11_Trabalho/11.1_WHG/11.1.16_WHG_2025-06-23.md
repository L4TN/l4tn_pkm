Lógica somente para Carteiras

Abri uma Carteira existente
    Se não tem Config de Info Carteira, então campo de Perfil Carteira fica desbloqueado para escolher algum perfil
    Caso contrário, se tem config de Info Carteira então os campos são preenchidos automaticamente

Criando uma Carteira nova
     não tem Config de Info Carteira, então campo de Perfil Carteira fica desbloqueado para escolher algum perfil
     Ao ser enviado a Request, o perfil é Criado
