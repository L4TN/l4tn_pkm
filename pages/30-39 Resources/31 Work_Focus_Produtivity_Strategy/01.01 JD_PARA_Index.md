# Johnny Decimal + PARA Index

This PKM system combines Johnny Decimal organization with PARA methodology.

## Areas (Johnny Decimal)
- 00-09 System - System management, MOCs, and templates
- 10-19 Projects - Time-bound work with specific outcomes
- 20-29 Areas - Ongoing responsibilities and life domains
- 30-39 Resources - Reference materials and evergreen knowledge
- 90-99 Archives - Completed/inactive items

## Navigation
- Use the numerical prefixes to quickly identify and locate information
- MOCs (Maps of Content) provide high-level navigation across areas
- Each area has index files for understanding the structure

## PARA Method Integration
- Projects: 10-19 Projects area

PARA vs LYT: Diferenças e Como Integrá-los
PARA Method (Tiago Forte)
Foco: Organização orientada a AÇÃO e RESULTADO
​

Estrutura
Projects - Resultados específicos com prazo

Areas - Responsabilidades contínuas

Resources - Tópicos de referência

Archives - Itens inativos

Características
Hierárquico e funcional

Orientado a produtividade e GTD (Getting Things Done)

Baseado em pastas/categorias fixas

Pergunta central: "Para que serve isso no meu trabalho/vida?"

Ideal para: Executar projetos, gerenciar tarefas, produtividade

LYT - Linking Your Thinking (Nick Milo)
Foco: Organização orientada a IDEIAS e CONEXÕES
​

Estrutura
MOCs (Maps of Content) - Mapas que conectam notas relacionadas

Notas atômicas - Uma ideia por nota

Links bidirecionais - Conexões orgânicas entre ideias

Emergence structures - Estrutura emerge das conexões

Características
Não-hierárquico e fluido
​

Orientado a descoberta e pensamento criativo

Baseado em links/grafos dinâmicos

Pergunta central: "Como essa ideia se conecta com outras?"

Ideal para: Pesquisa, escrita, pensamento profundo, criatividade

Diferenças Fundamentais
Aspecto	PARA	LYT
Filosofia	Ação e execução	Pensamento e conexão
Estrutura	Fixa (4 categorias)	Emergente (MOCs)
Organização	Top-down (pastas)	Bottom-up (links)
Tempo	Orientado a prazos	Atemporal
Entrega	Completar projetos	Desenvolver ideias
Atomicidade	Opcional	Essencial
Mudança	Move entre categorias	Links permanecem

Como Funciona a Integração
PARA fornece a ESTRUTURA (onde guardar)
​

Pastas organizadas por função

Claro onde colocar novos itens

Fácil de arquivar quando completo

LYT fornece as CONEXÕES (como relacionar)
​

MOCs atravessam categorias PARA

Links bidirecionais entre notas

Ideias emergem das conexões

Quando Usar Cada Método
Use PARA quando:
Precisa decidir ONDE salvar algo

Está gerenciando projetos com prazo

Quer limpar arquivos antigos

Busca por tipo (projeto vs referência)

Faz weekly review de tarefas

Use LYT quando:
Está desenvolvendo uma ideia complexa

Quer descobrir conexões não óbvias

Escreve artigos ou faz pesquisa

Precisa ver relações entre conceitos

Faz brainstorming ou pensamento criativo

Use PARA + LYT quando:
Quer sistema completo (estrutura + conexão)

Gerencia trabalho E conhecimento

Precisa executar E pensar profundamente

Quer escalabilidade com flexibilidade
